# 产品文档阅读入口

当前版本为 V3.3，整理日期为2026年11月3日。

| 文档 | 推荐读者 | 阅读版 | 编辑源文档 |
| --- | --- | --- | --- |
| 产品需求文档 | 产品、研发和测试 | [PRD 浏览器阅读版](PRD_V3.3.html) | [PRD Markdown](PRD.md) |
| 产品介绍与使用指南 | 新用户、运营和宣传人员 | [图文使用指南](USER_GUIDE.html) | [使用指南 Markdown](USER_GUIDE.md) |
| 原始规划 | 需要了解早期设计的人 | 不适用 | [原始规划](PRD.original-plan.md) |

HTML 可直接用浏览器打开，无需启动网站。分享时保留 `assets/` 与文档的相对位置，或发送整体文档压缩包。配图是结构示意，不是截图。浏览器打印可选择保存为 PDF，排版已提供 A4 打印样式。

更新 `PRD_V3.3.md` 或 `USER_GUIDE.md` 后，在项目根目录执行 `node docs/build-product-docs.mjs` 重新生成阅读版与配图；主入口 `PRD.md` 应与对应版本源文档同步。早期规划里的未实现功能不用于对外介绍。
